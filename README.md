# Resume Builder & ATS Screener

A lightweight open-source web app for building resumes and checking them against a target job description.

## Features

- Resume form with personal details, summary, skills, experience, and education
- ATS score based on keyword alignment with the target role
- Missing keyword suggestions
- Live resume preview
- Works without a database or third-party SaaS dependency

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Project goals

This starter app is designed as an open-source MVP for job seekers to:

- create a polished resume quickly
- compare the resume against a job description
- identify missing keywords and optimize application materials

## Future enhancements

- resume templates
- PDF export
- saved resume history
- AI-powered editing suggestions
- multi-role resume variants
- open-source database layer for persistence
